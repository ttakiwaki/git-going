# Fall Hacks 2026 - Git & GitHub Workshop

Welcome to the Fall Hacks 2026 Git & GitHub Workshop! This workshop is designed to help you get started with Git and GitHub, two essential tools for version control and collaboration in software development.

---

## Step 0: Fork this repository

Before you do anything else, you need your own copy of this project to work on.

1. Click the "Fork" button at the top right corner of this page. This will create a copy of this repository under your GitHub account.
2. Once you have forked the repository, you can now clone this repository to your local machine.
3. To clone the repository, click the green "Code" button and copy the URL provided. Then, open your terminal and run the following command:

```bash
git clone <URL>
```

4. Open the cloned repository in your favorite code editor (e.g., VS Code, Vim, Zed).
