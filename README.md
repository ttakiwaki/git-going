# Git Going: Workshop Sandbox

Welcome to the hands-on portion of the Git & GitHub workshop! You and your partner will use this repository to practice:

1. Hiding secret `.env` files using `.gitignore`
2. Creating branches and opening Pull Requests
3. Triggering and resolving a real Merge Conflict

## Repository Structure

- app.py — A simple script used to test environment variables in Phase 3.
- .env.example — Template file for practicing local secrets configuration.
- .gitignore — The rulebook telling Git which files (like `.env`) to ignore.
- team_card.md — The shared file used for practicing branches, PRs, and merge conflicts.
